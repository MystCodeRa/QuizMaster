# QuizMaster 🧠

QuizMaster is a command-line quiz application developed with Python. It allows users to test their knowledge in different subjects, track their scores, and improve their performance.

## Features

- **Multiple Quiz Categories:** Choose between Python, Computer Science, and Cybersecurity.
- **Interactive Questions:** Answer multiple-choice questions.
- **Answer Validation:** Invalid answers are rejected.
- **Score System:** Earn 10 points for each correct answer.
- **Success Rate:** View your quiz performance as a percentage.
- **Personal Best:** Track your highest score in each category.
- **Leaderboard:** Compare scores with other players.
- **Replay Option:** Play the quiz again without restarting the application.
- **JSON Score Storage:** Save quiz results in a JSON file.

## Getting Started

### 1. Clone the Repository

```bash
git clone YOUR_REPOSITORY_URL
```

### 2. Navigate to the Project Directory

```bash
cd QuizMaster
```

### 3. Run the Application

```bash
python3 src/main.py
```

## How to Play

1. Enter your name.
2. Select a quiz category.
3. Answer the multiple-choice questions.
4. Get 10 points for each correct answer.
5. View your final score and success rate.
6. Check your personal best and the category leaderboard.
7. Choose whether to play again.
